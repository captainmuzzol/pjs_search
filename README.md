# 判决文书极速搜索工具

一个基于SQLite的高效判决文书搜索工具，支持智能搜索、精准搜索和范围筛选等功能，帮助用户快速检索和分析判决文书。主要用于无网络、专用网络环境下的办案需要，支持国产麒麟（arm64）。
## 主要功能

### 1. 搜索功能
- **智能搜索**：自动将输入内容拆分为关键词，寻找包含所有关键词的文档
- **精准搜索**：按原文搜索输入的关键词，支持空格分隔多个词语
- **排除搜索**：支持设置排除词，过滤不需要的搜索结果
- **范围筛选**：可选择搜索全部案件、刑事案件或民事案件

### 2. 数据源选择
- XX法院XXXX前数据
- XX中院XXXX前数据
- 支持自定义数据库

### 3. 高级功能
- **姓名热力解析**：统计文件夹中被告人姓名出现频次
- **身份信息提取**：提取被告人/原告身份证信息
- **搜索结果导出**：支持将搜索结果导出为文本文件

## 使用说明

1. **基本搜索**
   - 在主搜索框输入关键词，多个词语用空格分隔
   - 在排除搜索框输入不需要的关键词（可选）
   - 选择搜索方式（智能/精准）
   - 点击搜索按钮开始检索

2. **查看结果**
   - 双击搜索结果可打开文件预览
   - 预览界面支持关键词高亮显示

3. **数据选择**
   - 从下拉框选择需要搜索的数据库
   - 使用范围按钮切换案件类型

## 技术特点

- 基于SQLite数据库，确保搜索性能
- 使用jieba分词实现智能搜索
- PyQt5构建用户界面，提供良好的交互体验
- 支持文档预览和关键词高亮

## 安装说明

1. 确保系统已安装Python环境
2. 安装必要的依赖包：
   ```
   pip install PyQt5 jieba sqlite3
   ```
3. 运行主程序：
   ```
   python search_app_SQL.py
   ```

## 打包说明

使用PyInstaller打包程序：
```
pyinstaller -w -i 判决检索.ico search_app_SQL.py
```
注意：打包时需要将jieba文件夹拷贝到dist目录。

## 注意事项

- 本程序仅供交流学习使用
- 姓名热力解析可能存在同名重复统计的情况
- 建议定期更新数据库以获取最新的判决文书信息
